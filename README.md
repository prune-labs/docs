# Prune Docs

This directory contains documentation for Prune. You can find content in content/docs in repo, link: [https://prune-rose.vercel.app/]. The docs are built using Fumadocs.

## Contributing

If you want to contribute to the documentation, please follow these steps:

- Fork the repository and create a new branch for your changes.
- Make your changes to the documentation files in the `content/docs` directory, OR change lp home.
- Find issues, fix typos, or add new content to the documentation.
